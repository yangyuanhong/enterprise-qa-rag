# 费用报销流程

## 一、报销范围
差旅费、交通费、业务招待费、办公用品采购费、培训费等因公产生的费用。

## 二、差旅标准
1. 住宿标准：一线城市（北京、上海、广州、深圳）普通员工每晚 500 元，经理级每晚 700 元；其他城市普通员工每晚 350 元，经理级每晚 500 元。
2. 交通标准：高铁二等座、飞机经济舱；经理级以上可乘坐高铁一等座。
3. 出差补贴：每天 100 元，按实际出差天数计算。
4. 市内交通：出差期间打车费用凭发票实报实销。

## 三、报销流程
1. 在 OA 系统中填写报销单，上传电子发票或纸质发票照片。
2. 部门负责人审批。
3. 单笔金额超过 5000 元需分管副总审批。
4. 财务部审核票据。
5. 审批通过后，财务会在 5 个工作日内打款到员工工资卡。

## 四、注意事项
1. 费用发生后 30 天内必须提交报销，逾期不予报销。
2. 发票抬头须为"示例科技有限公司"，并填写正确税号。
3. 业务招待费需注明招待对象和事由。
4. 超出标准的部分由个人承担。
